v0.6.4 是 v0.6.3 之后的 patch 版本：修复 macOS 增量安装、Windows 补丁路径、Linux 输入法生命周期与文本回调状态等问题，并新增签名增量更新、编辑器多选区、Select 图标与浮层、表格单元格矩形、无头测试时钟与可访问性查询等能力。已有导出 API 不变，升级不需要改调用点。macOS 是参考平台。

v0.6.4 is a patch release after v0.6.3: it fixes macOS delta installation, Windows patch paths, Linux input-method lifetimes and stale text callbacks, and adds signed delta updates, multi-selection in editors, Select icons and floating popups, table cell rectangles, and headless test clocks and accessibility queries. Existing exported APIs are unchanged, so upgrading needs no call-site edits. macOS is the reference platform.

## 拿到它 · Getting it

`go get github.com/vivaui/viva@v0.6.4`，需要 Go 1.26 或更新；系统依赖与 v0.6.3 相同。每个 Release 附带 `viva` 命令的预编译压缩包、`SHA256SUMS`，以及 Homebrew 与 Scoop 清单（`brew install vivaui/tap/viva`，或 `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` 后 `scoop install viva`）；压缩包没有代码签名或公证，浏览器下载的 macOS 版会被 Gatekeeper 拦下，brew、curl 与 `go install` 不受影响。

`go get github.com/vivaui/viva@v0.6.4` needs Go 1.26 or newer; the system requirements are those of v0.6.3. Every Release carries prebuilt archives of the `viva` command, `SHA256SUMS`, and Homebrew and Scoop manifests (`brew install vivaui/tap/viva`, or `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` then `scoop install viva`); the archives are not code-signed or notarized, so a browser download on macOS is stopped by Gatekeeper while brew, curl and `go install` are not affected.

## 有什么 · What is in it

- 增量更新：签名 feed 可以为每个资产声明补丁（`viva feed --patch-from`）；`DownloadPatch` 校验 feed 声明的字节，`ReadPatch` 与 `PatchReader.Apply` 校验它写入的每个文件，`ApplyPatch` 暂存结果，`Install` 用暂存 payload 替换应用；补丁不适配时回退全量包
- Windows 的补丁携带便携 zip 的目录内容，同一补丁可用于 NSIS 安装与便携副本；PowerShell helper 保留备份，新程序启动失败时回滚；机器级安装回退完整安装器
- `ContentWindow.Frame` 与 `ContentWindow.Minimized` 暴露内容窗口的 frame 与最小化状态，跨窗口拖放可以按 frame 命中
- 单元格字形按字体自身的 box drawing 墨宽绘制，CoreText、DirectWrite 与 Pango 分别测量 light/heavy 字形；提示边框不再随显示缩放变细
- `viva package --format pkgbuild` 生成 Arch Linux 的 `PKGBUILD` 与 `.SRCINFO`，应用可以通过 `[linux] arch_depends` 声明额外的 Arch 包
- `ui.SelectIcon` 给每个选项一个图标，`Box.Icons` 在 Frame 层提供同一管线；没有图标时 Select 的绘制不变，warm frame 仍然零分配
- `SelectOptions.Viewport` 让下拉列表浮在祖先滚动裁剪之外，行、滚动条与命中都按整页计算；滚动位置、焦点范围、Escape 与 dismiss 行为不变
- `TableState.CellRect` 报告上次绘制中源单元格的窗口坐标矩形；行列是源索引，滚动与排序不会重编号，矩形也不会被裁剪
- `CodeEditorRun.Italic` 让高亮器把注释画成斜体，固定宽度后端已经读取 `TextRun.Italic`，不需要新的平台代码
- 编辑器支持多选区：`Selections`、`SelectionsInto`、`SelectionSpansInto`、`AddSelection`、`SetSelections` 与 `ClearSecondarySelections`，插入与删除作为一个 undo 单元；字段与代码编辑器绘制全部选区，光标只在主选区
- 无头 session 的 `Now`、`Advance`、`Frame`、`Transitioning` 提供测试自己的时钟；`Access`、`AccessByRole`、`AccessByName` 读取上一帧的可访问性树，`Notifications` 返回应用发送的通知
- macOS 上缺失路径的图标按文件类型解析
- IBus 解码 `UpdatePreeditText`（`vub`）与 `UpdatePreeditTextWithMode`（`vubu`），保留 Update、Show、Hide 与 mode/visibility 来源；旧式 Update 清除 mode 来源，畸形 body 不能覆盖缓存快照 (contributed by @caichangqing1120) (PR [#258](https://github.com/vivaui/viva/pull/258))
- IBus 的 `Context.Close` 改在 `org.freedesktop.IBus.Service` 上 Destroy，先摘本地 owner 再发送，已退休的 context 不再接受请求，重复 Close 或 path 被替换后也不会误删当前 owner 的 handler (contributed by @caichangqing1120) (PR [#267](https://github.com/vivaui/viva/pull/267))
- GTK 窗口销毁前先 focus-out、清 client window、unref IM context，默认 delete-event 走同一条销毁路径；Fcitx 下关窗口不再触发 GLib critical (contributed by @caichangqing1120) (PR [#268](https://github.com/vivaui/viva/pull/268))
- Linux 文本回调按 revision 区分过期确认、仅几何同步与过期重绘；关闭输入后作废在途回调、停止光标定时器并拒绝复活 (contributed by @caichangqing1120) (PR [#259](https://github.com/vivaui/viva/pull/259))
- Linux rich clipboard 在声明 X11 selection 或调用桌面 hook 之前拒绝 NUL，并把这些 native 剪辑板、合成与图标契约测试加入 CI (contributed by @caichangqing1120) (PR [#264](https://github.com/vivaui/viva/pull/264))
- 菜单行高跟随 `theme.Metrics.ControlHeight`（密度 compact 26、默认 32、large 40），绘制高度与 `ui.MenuItems` 的预留高度一致；显式 `RowHeight` 仍然优先 (contributed by @xiaoyumuxi) (PR [#265](https://github.com/vivaui/viva/pull/265))
- textcache 的准入分为 probation 与 protected 两段 LRU，main hit 才提升，避免 Count-Min 冲突误杀正在复用的 shaping 行 (contributed by @caichangqing1120) (PR [#263](https://github.com/vivaui/viva/pull/263))
- Windows payload 安装用 `Get-Item.FullName` 归一化 payload 与 backup 根路径，`RUNNER~1` 这类 8.3 短路径下不再把文件装到错误位置 (contributed by @caichangqing1120) (PR [#266](https://github.com/vivaui/viva/pull/266))
- macOS 增量安装把 payload 以运行 bundle 的名字暂存，文档中的 `ApplyPatch → Install` 顺序恢复可用 (contributed by @xiaoyumuxi) (PR [#269](https://github.com/vivaui/viva/pull/269))
- 补丁生成只为 Windows 便携 zip 生成补丁，不再尝试 diff NSIS setup
- `iconcompile` 支持 use 元素与顶点标记

- Delta updates: a signed feed may declare a patch per asset (`viva feed --patch-from`); `DownloadPatch` verifies the bytes the feed declares, `ReadPatch` and `PatchReader.Apply` verify every file a patch writes, `ApplyPatch` stages the result, and `Install` replaces the application from it; a patch that does not fit falls back to the full archive
- A Windows patch carries the portable zip's directory contents and applies to both an NSIS installation and a portable copy; the PowerShell helper keeps a backup and restores it when the new program fails to start, and a machine-wide installation falls back to the full installer
- `ContentWindow.Frame` and `ContentWindow.Minimized` expose the content window's frame and minimize state, so a drag across windows can hit-test by frame
- Cell glyphs use the font's own box-drawing ink width, measured separately by CoreText, DirectWrite and Pango for the light and heavy glyphs, so a prompt border no longer thins out with display scale
- `viva package --format pkgbuild` writes an Arch Linux `PKGBUILD` and `.SRCINFO`, and `[linux] arch_depends` names the extra Arch packages an application needs
- `ui.SelectIcon` gives every option an icon, with `Box.Icons` providing the same plumbing at the Frame's layer; a select without icons paints what it always painted and warm frames allocate nothing
- `SelectOptions.Viewport` floats the open list outside ancestor scroll clips, including its rows and scrollbar; scroll position, focus scope, Escape and dismiss behaviour are unchanged
- `TableState.CellRect` reports where a source cell was painted in window coordinates; rows and columns are source indices, so scrolling and sorting do not renumber them and the clip does not cut the rectangle
- `CodeEditorRun.Italic` lets a highlighter slant a comment; every fixed-pitch backend already reads `TextRun.Italic`, so no new platform code is needed
- Editors support multiple selections: `Selections`, `SelectionsInto`, `SelectionSpansInto`, `AddSelection`, `SetSelections` and `ClearSecondarySelections`, with insert and delete applied as one undo unit; fields and the code editor paint every selection and keep the caret on the primary one
- A headless session's `Now`, `Advance`, `Frame` and `Transitioning` give a test its own clock; `Access`, `AccessByRole` and `AccessByName` read the last frame's accessibility tree, and `Notifications` returns what the application sent
- On macOS, a missing path's icon is resolved from its type
- IBus decodes `UpdatePreeditText` (`vub`) and `UpdatePreeditTextWithMode` (`vubu`), preserving Update, Show, Hide and the mode/visibility provenance; an older Update clears the mode source, and a malformed body cannot replace the cached snapshot (contributed by @caichangqing1120) (PR [#258](https://github.com/vivaui/viva/pull/258))
- IBus `Context.Close` destroys the context on `org.freedesktop.IBus.Service`, drops the local owner before sending, and refuses requests from retired contexts, so a repeated Close or a replaced path cannot remove the current owner's handler (contributed by @caichangqing1120) (PR [#267](https://github.com/vivaui/viva/pull/267))
- A GTK window detaches its input method (focus-out, client window cleared, unref) before widget destruction, and the default delete event uses the same path, so closing a window under Fcitx no longer raises a GLib critical (contributed by @caichangqing1120) (PR [#268](https://github.com/vivaui/viva/pull/268))
- Linux text callbacks use revisions to tell a stale acknowledgment from a geometry-only sync and a stale redraw; closing an input invalidates in-flight callbacks, stops its caret timer and refuses revival (contributed by @caichangqing1120) (PR [#259](https://github.com/vivaui/viva/pull/259))
- Linux rich clipboard writes reject NUL before claiming the X11 selection or invoking the desktop hook, and the native clipboard, compositing and icon contract tests now run in CI (contributed by @caichangqing1120) (PR [#264](https://github.com/vivaui/viva/pull/264))
- Menu rows take the theme's control height (26 at compact density, 32 at default, 40 at large) and move together with the height `ui.MenuItems` reserves; an explicit `RowHeight` still wins (contributed by @xiaoyumuxi) (PR [#265](https://github.com/vivaui/viva/pull/265))
- The text cache splits admission into probation and protected LRU segments and promotes on a main hit, so Count-Min collisions no longer evict a reused shaped line (contributed by @caichangqing1120) (PR [#263](https://github.com/vivaui/viva/pull/263))
- The Windows payload installer normalizes the payload and backup roots through `Get-Item.FullName`, so an 8.3 root such as `RUNNER~1` no longer installs files under the wrong path (contributed by @caichangqing1120) (PR [#266](https://github.com/vivaui/viva/pull/266))
- A macOS delta install stages the payload under the running bundle's name, so the documented `ApplyPatch -> Install` order works (contributed by @xiaoyumuxi) (PR [#269](https://github.com/vivaui/viva/pull/269))
- Patch generation only patches the portable Windows zip and no longer tries to diff the NSIS setup
- `iconcompile` learns use elements and vertex markers

## 注意 · Caveats

- 本版使用 patch 版本号，但包含新增 API；没有删除或改变已有导出 API，升级不需要迁移
- Windows 的机器级安装仍然使用完整安装器；增量补丁覆盖便携副本与用户级安装
- textcache 的准入改动让 warm hit 路径变慢：本机 `BenchmarkWorkingSet/512` 从约 9.1 µs 升到 11.6 µs（贡献者报告约 +42%），换来更稳定的复用命中；这部分会单独优化
- 菜单行的默认高度仍是 32；只有 compact 与 large 主题分别变为 26 与 40
- 组合输入、受限/覆盖编辑器、移动与 Undo/Redo 结束后只保留主选区

- This release uses a patch version number but adds APIs; no existing exported API is removed or changed, so no migration is needed
- Windows machine-wide installations still use the full installer; delta patches cover the portable copy and user-level installations
- The text-cache admission change slows the warm-hit path: `BenchmarkWorkingSet/512` goes from about 9.1 us to 11.6 us here (the contributor reports about +42%), in exchange for steadier reuse hits; that path will be optimized separately
- The default menu row height is still 32; only the compact and large themes change to 26 and 40
- A composition, restricted or overwriting editor, movement, and Undo/Redo end with only the primary selection
